# Ночь в Перми — история Вари

Мобильное игровое веб-приложение на чистом HTML, CSS и JavaScript. Его можно разместить в корне репозитория и включить GitHub Pages для ветки main и папки root.

В игре есть стартовый экран, выбор одного из пяти образов Вари, вступительная сцена в Перми, десять встреч по пять вопросов и 21 концовка. Персонажи рассказывают свою историю и отвечают на пять вопросов Вари; затем она выбирает одно из двух действий. Прошлые решения меняют последующие реплики и подсказки. Егор, Кира, Витя и Никита скрыто сбивают Варю с пути как аномалии хэллоуинской ночи. Финальная сцена всегда происходит на тыквенном поле. От всей цепочки решений зависит, вернётся ли Джек на свою грядку: шесть концовок тревожные, но Варя во всех остаётся в безопасности. Вариант «Это был сон» — одна из концовок. Секретная комическая концовка «Алхимический перебор» доступна только готической алхимик: нужно выпить собственные зелья у Алёны и Максима, а затем пройти все встречи до поля.

Открой index.html в браузере или запусти локальный статический сервер. На телефоне интерфейс адаптируется под узкий экран и складывает портрет персонажа и фото локации одно под другим. Переходы и кнопки анимируются на телефоне и ПК; при включённом системном уменьшении движения анимация отключается. Приложение включает веб-манифест, иконку и сервис-воркер для кэширования оболочки.

Фотографии уже обработаны и находятся в папке assets; соответствие персонажей и локаций указано в assets/README.md.
